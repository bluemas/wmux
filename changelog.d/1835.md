### Added

- **Cmd+Backspace deletes the previous word on macOS.** In a terminal pane, Cmd+Backspace now erases the word before the cursor, as it does in other macOS text fields. It works in shells (bash, zsh), vim's insert mode and Claude Code. Before, the key did nothing. If you have bound Cmd+Backspace to a shortcut yourself, your binding still takes priority. (#1835)
