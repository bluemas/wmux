### Added

- **Plugins can browse folders and read files.** A plugin that asks for the
  new "files" permission, and that you approve, can list local folders and
  read text files up to 1 MB. Before, a plugin could not see the filesystem
  at all. Credential folders such as `~/.ssh` stay off-limits, and the
  permission cannot change or delete anything. It is the first step toward a
  dual-panel file manager plugin.
