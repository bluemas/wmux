### Added

- **Claude Code panes resume themselves when wmux starts.** After a restart, a pane that was running Claude Code now picks up its conversation by itself once the shell is ready. You no longer have to click the Resume pill and press Enter. It resumes the exact conversation when the pane is still in the same folder, otherwise the folder's most recent one, with the same permission mode as before. Skipping permissions is never turned on automatically. Other agents still use the Resume pill. (#1826)
